# Tags

## Status tags

| Tag | Meaning |
|---|---|
| `:source:` | A source note or a note primarily recording source material. |
| `:my-thinking:` | The user's developing analysis or synthesis. |
| `:open-question:` | A question that remains unresolved. |
| `:review:` | Extensive, low-confidence agent-authored material needing user review. |

Tags are optional. Introduce a new tag only when existing vocabulary cannot
express the need; consolidate near-duplicates during an approved review.
